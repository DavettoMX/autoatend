Documentación de la API

Servicio web HTTP REST local de AutoAtend. Las respuestas son JSON en UTF-8.

POST POST /api/clasificar

Clasifica un comentario en una de las cinco categorías y devuelve la confianza de cada una y los lexemas que más pesaron en la decisión.

Cuerpo de la solicitud (JSON, máximo 1 MB)

CampoTipoDescripción
textocadenaObligatorio. Comentario del cliente; no puede estar vacío.

Ejemplo de solicitud

POST /api/clasificar
Content-Type: application/json

{"texto": "Me atendieron por correo y quedó resuelto, aunque tuve que insistir 5 veces. Gracias."}

200 Ejemplo de respuesta

{
  "categoria": "Reconocimientos",
  "confianzas": {
    "Cobros Indebidos": 0.0060,
    "Falta de Servicio": 0.0045,
    "Problemas de Facturación": 0.0042,
    "Quejas": 0.4653,
    "Reconocimientos": 0.5200
  },
  "lexemas_clave": [
    { "lexema": "atendieron", "expresion_regular": "atendieron", "contribucion": 0.9985 },
    { "lexema": "gracias", "expresion_regular": "graci(as|s)", "contribucion": 0.6831 }
  ],
  "vacio": false
}

Respuestas de error

400 Solicitud no válida

El cuerpo está vacío, no es JSON válido o falta el campo texto (o está en blanco). Los tres mensajes posibles:

{"error": "El cuerpo esta vacio; envie un JSON con el campo \"texto\"."}
{"error": "JSON no valido; se espera {\"texto\": \"...\"} con el texto como cadena."}
{"error": "El campo \"texto\" es obligatorio y no puede estar vacio."}

413 Cuerpo demasiado grande

El cuerpo de la solicitud supera 1 MB.

{"error": "El cuerpo de la solicitud supera el maximo de 1048576 bytes (1 MB)."}

405 Método no permitido

Se usa un método distinto de POST. La respuesta incluye el encabezado Allow: POST.

{"error": "Metodo GET no permitido; use POST."}
Envía el comentario de la solicitud de ejemplo. 


  


  

    
GET GET /api/lexemas

    
Catálogo de expresiones regulares: una entrada por lexema, con su forma canónica, la expresión regular que reconoce sus variantes y su frecuencia global y por categoría. Está paginado.

    
Parámetros de consulta (todos opcionales)

    

      
ParámetroDescripción

      
        
paginaEntero ≥ 1. Predeterminado: 1.

        
tamanioEntero ≥ 1 (máximo 500). Predeterminado: 100.

        
qPrefijo de la forma canónica (máximo 100 caracteres).

        
ordenfrecuencia o variantes. Sin valor: orden alfabético.

        
min_frecuenciaEntero ≥ 0. Oculta los lexemas con menos apariciones.

      
    

    
200 Ejemplo de respuesta

    
{
  "total": 773,
  "pagina": 1,
  "tamanio": 1,
  "lexemas": [
    {
      "forma_canonica": "cobro",
      "expresion_regular": "cobr(ado|ando|ar|aron|o|os)",
      "frecuencia_global": 9009,
      "frecuencias": { "Cobros Indebidos": 7253, "Falta de Servicio": 507, "Problemas de Facturación": 314, "Quejas": 637, "Reconocimientos": 298 },
      "variantes": 6
    }
  ]
}

    
Respuestas de error

    
400 Parámetro no válido

    
pagina, tamanio, orden o min_frecuencia no son válidos, o q supera 100 caracteres. Ejemplos:

    
{"error": "El parametro \"pagina\" debe ser un entero >= 1."}
{"error": "El parametro \"orden\" debe ser \"frecuencia\" o \"variantes\"."}

    
405 Método no permitido

    
Se usa un método distinto de GET. La respuesta incluye el encabezado Allow: GET.

    
{"error": "Metodo POST no permitido; use GET."}

    

      
      Consulta fija: /api/lexemas?pagina=1&tamanio=3&orden=variantes&min_frecuencia=100

GET GET /api/health

    
Estado del servicio: versión, número de lexemas del catálogo y puerto en el que escucha. No recibe parámetros.

    
200 Ejemplo de respuesta

{"error": "Metodo POST no permitido; use GET."}

    

      
      Consulta: /api/health
    

    

    

  


  

    
GET GET /

    
La página del clasificador (HTML). No devuelve datos, por eso no tiene botón de prueba: ábrala aquí. Las páginas /catalogo y /api (esta) solo presentan los datos de las rutas anteriores.

  


  

    
Otras respuestas de error

    
404 Ruta no encontrada

    
La ruta no existe; es el caso de cualquier ruta distinta de las cinco anteriores.

    
{"error": "Ruta no encontrada: /api/otra"}

    
500 Error interno

    
Falla interna al leer el catálogo. No ocurre en operación normal: las bases de datos se extraen y verifican al arrancar (y con --selftest).

    
{"error": "No se pudo leer el catalogo de lexemas."}
